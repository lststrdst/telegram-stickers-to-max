# Telegram Sticker Downloader for MAX

Скачивает публичный стикерпак Telegram по ссылке, переводит статичные стикеры в прозрачные PNG 288×288 и раскладывает их по папкам до 100 штук — остаётся выбрать файлы в официальном боте `@stickers` в MAX.

Зачем: потому что хуёвые стикеры в MAX заебали.

## Наглядная инструкция в Figma

[Открыть пошаговую инструкцию Telegram → MAX](https://www.figma.com/design/JB4Ev7iq5KeVvQP6Qjz2LZ/Telegram-MAX-instruktsiya)

Внутри шесть экранов: получение токена у `@BotFather`, запуск `sticker2max.cmd`, выбор папки с PNG, загрузка в официальный `@stickers` и сохранение набора. Листайте макеты слева направо.

## Что получается

```text
output/
└── Название пака — telegram_pack_name/
    ├── max_pack_01/
    │   ├── 001.png
    │   ├── 002.png
    │   └── ... до 100 файлов
    ├── max_pack_02/          # если в паке больше 100 стикеров
    ├── manifest.csv          # порядок и эмодзи из Telegram
    ├── report.json           # отчёт обработки
    └── MAX_UPLOAD.txt        # короткая инструкция по загрузке
```

PNG сохраняют пропорции и прозрачность. Изображение вписывается в холст 288×288 без растягивания и обрезки.

## Быстрый запуск на Windows

1. Установите [Python 3.10+](https://www.python.org/downloads/windows/) и включите `Add python.exe to PATH` в установщике.
2. В Telegram откройте `@BotFather`, выполните `/newbot` и получите токен. Бот нужен только как ключ к официальному Telegram Bot API; добавлять его в чаты не требуется.
3. Запустите `sticker2max.cmd` двойным щелчком.
4. Вставьте ссылку вида `https://t.me/addstickers/PackName` и нажмите Enter.
5. Вставьте токен бота в скрытый запрос. Токен не отображается и не сохраняется.

При первом запуске `.cmd` сам установит Pillow. После обработки откроется папка `max_pack_01`, а скрипт предложит открыть официальный бот MAX.

Можно передать ссылку прямо в CMD:

```cmd
sticker2max.cmd https://t.me/addstickers/faartzwc_by_stickrubot
```

Несколько паков за один запуск:

```cmd
sticker2max.cmd https://t.me/addstickers/PackOne https://t.me/addstickers/PackTwo
```

Если при запуске просто нажать Enter, программа обработает все ссылки из `packs.txt`.

## Как загрузить в MAX

1. Откройте официальный бот [`@stickers`](https://max.ru/stickers).
2. Новый пак: `Начать` → `Создать набор`.
3. Существующий пак: `Открыть` → выбрать набор → меню → `Редактировать`.
4. Нажмите `Добавить стикеры` → `С устройства`.
5. Откройте подготовленную папку `max_pack_01`, нажмите `Ctrl+A` и `Открыть`.
6. Если веб-интерфейс зависает на большой пачке, выбирайте по 20–25 PNG за раз в тот же набор.
7. Назначьте эмодзи/слова и сохраните набор.

По [официальным требованиям MAX](https://help.max.ru/help/bots/kak-zagruzit-svoi-stikery), в одном наборе может быть до 100 стикеров. Статичные изображения принимаются в JPG/JPEG/PNG, должны быть не меньше 288 пикселей по каждой стороне и не больше 10 МБ. Для публикации собственного набора нужен ранее созданный Цифровой ID.

Публичный MAX Bot API не предоставляет методов создания и редактирования стикерпаков, поэтому последний шаг выполняется в `@stickers`.

## Повторный запуск

Программа сверяет `file_unique_id` из Telegram и повторно использует только актуальные, уже проверенные PNG. Если пак изменился, нужные файлы обновятся, а лишние PNG из созданных программой папок удалятся.

Полностью пересобрать картинки:

```cmd
sticker2max.cmd --overwrite https://t.me/addstickers/PackName
```

Дополнительно сохранить исходные WEBP:

```cmd
sticker2max.cmd --keep-source https://t.me/addstickers/PackName
```

Создать ZIP каждой части для хранения:

```cmd
sticker2max.cmd --zip https://t.me/addstickers/PackName
```

Все параметры:

```cmd
python sticker2max.py --help
```

## Ограничения

- Подготавливаются статичные стикеры Telegram.
- Анимированные TGS и видео WEBM не превращаются в кадр: они отмечаются как пропущенные в `manifest.csv` и `report.json`.
- Для скачивания используется официальный [`getStickerSet`/`getFile`](https://core.telegram.org/bots/api) Telegram Bot API. Его лимит скачивания одного файла — 20 МБ.
- Токен можно не вводить каждый раз, если заранее создать переменную среды `TELEGRAM_BOT_TOKEN`.

Пример для постоянной переменной среды Windows:

```cmd
setx TELEGRAM_BOT_TOKEN "123456789:YOUR_BOT_TOKEN"
```

После `setx` нужно открыть новое окно CMD. Не публикуйте токен и не добавляйте его в `packs.txt`.
